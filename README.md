# Bekemon

A creative-level visual analytics and campaign intelligence platform for marketing agencies.

## Run

### 1. Requirements
- Node.js 18+
- npm, pnpm, or yarn

### 2. Install dependencies
```bash
npm install
```

### 3. Environment configuration (optional)
```bash
cp .env.example .env.local
```

### 4. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Run the tests
```bash
npm test
```

### 6. Build for production
```bash
npm run build
npm start
```
